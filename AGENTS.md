# Bibliotheca

Bibliotheca is a household book catalogue with an ASP.NET Core API and a Vue PWA. Read [the agent guide](docs/agent-guide.md) for the architecture, local validation commands and GitHub workflow.

Use `$bibliotheca-issues` to read the GitHub backlog or an issue with gh. Use `$bibliotheca-deliver` to develop and validate a selected issue and carry out authorized GitHub delivery. For .NET work, consult the relevant official skills under `.agents/skills`. The [agent guide](docs/agent-guide.md) lists when to use them.

Use `$bibliotheca-prototype` to build a runnable experiment and test feasibility. Use `$bibliotheca-engineer` to turn a prototype into a maintained feature that fits the existing architecture.
